### Project Overview

**SkillShikhi** is an end-to-end collaborative peer learning and skill-sharing platform designed to connect learners and mentors through interactive scheduling, resource sharing, and community engagement.

Built with an MVC architecture, the application emphasizes responsive user interfaces, robust data security, and efficient API data exchange.

### Architectural Features

- **Frontend Architecture**: Modern UI developed with **Next.js** and **React**, featuring server-side rendering (SSR), dynamic nested routing, and responsive mobile-first styling.
- **Backend & Database**: Robust backend services developed in **Node.js** and **Express**, paired with a **MongoDB** document database via Mongoose ORM.
- **Security & Authentication**: Secure JSON Web Token (JWT) session handling, encrypted password hashing via bcrypt, and fine-grained role-based access control (RBAC).
- **RESTful API**: Comprehensive API endpoints supporting CRUD operations for course catalogs, interactive user profiles, session reservations, and review ratings.
